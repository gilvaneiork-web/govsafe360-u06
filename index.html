Limites do laboratório

  • Não é sistema institucional homologado pela SEMA/MT.
  • Usa somente dados fictícios; não informe dados pessoais, senhas ou tokens.
  • Não há login, banco de dados, API nem conexão com sistemas oficiais.
  • As decisões são didáticas e não substituem normas nem autorizações oficiais.
  • Os cenários ficam salvos só neste navegador (localStorage). Em computador compartilhado, limpe ao terminar.
